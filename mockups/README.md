# Mockup Ghi Chú (HTML tĩnh)
Mở file .html trực tiếp trong trình duyệt. Phông chữ nằm trong ./fonts, ảnh minh hoạ trong ./img (không tải gì từ mạng).
Xuất lại ảnh PNG (từ /workspace/notes-app):
  node mockups/render.mjs '[{"file":"a-danh-sach.html","out":"1-phuong-an-A-danh-sach.png","w":1280,"h":800}]'
  (thêm "?menu=1" vào file để mở menu Thêm mới; "full":true để chụp cả trang; "dpr":2 cho ảnh điện thoại)
